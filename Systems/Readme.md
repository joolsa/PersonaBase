# Persona Systems Overview

Persona systems are computational frameworks and tools that generate, simulate, or represent user archetypes ("personas") from various types of data. They are used in domains such as design, AI research, and social simulation to model user needs, behaviors, and perspectives for evaluation, development, or decision-making.

| ID   | Name of system                         | Year introduced | Description                                                                                                                                                                                                                                                                  | URL                                                                                      |
|------|-----------------------------------------|-----------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------|
| PS01 | Automatic Persona Generation (APG)      | 2018            | Comprehensive six-stage automated system using Non-negative Matrix Factorization for large-scale social media data processing into rich persona profiles. Handles hundreds of millions of interactions with real-time monthly updates.                                          | [Link](https://persona.qcri.org)                                                         |
| PS02 | Survey2Persona (S2P)                    | 2022            | Interactive web-based system specifically designed for converting survey responses into persona representations using machine learning clustering and generative AI. Supports CSV/Excel files from Google Forms, SurveyMonkey, Qualtrics.                                      | [Link](https://s2p.qcri.org)                                                             |
| PS03 | PersonaGen                              | 2023            | Tool for generating personas from user feedback using GPT-4 model and knowledge graphs. Designed for agile software development processes to facilitate requirement analysis by processing well-structured user feedback into persona templates.                               | [Link](https://arxiv.org/abs/2307.00390)                                                 |
| PS04 | Generative Agents                       | 2023            | Computational software agents simulating believable human behavior in interactive sandbox environments. Architecture extends LLMs to store complete records of agent experiences, synthesize memories into reflections, and retrieve them dynamically.                          | [Link](https://arxiv.org/abs/2304.03442)                                                 |
| PS05 | Vivid-Persona                           | 2024            | Multimodal persona system architecture combining Stable Diffusion, ChatGPT, and real-time video generation for interactive persona creation. Features persona setting, persona generating, and immersive conversation phases.                                                   | [Link](https://www.tandfonline.com/doi/full/10.1080/09544828.2024.2383543)               |
| PS06 | Crafter                                 | 2024            | LLM-based system using GPT-3.5 for domain-specific persona generation in software requirements engineering with customizable templates. Features two-layer personas with internal background and external context-specific information.                                        | [Link](https://doi.org/10.5220/0012718400003687)                                         |
| PS07 | Character-Centric Story Generation      | 2024            | Framework using images for persona generation with DALL-E 3 and GPT-4o for character imagination and story generation. Features Image Guided Imagination and Persona Personality Traits components for content generation.                                                       | [Link](https://arxiv.org/abs/2409.16667)                                                 |
| PS08 | Agentic Society System                  | 2024            | System merging skeleton from real world data with texture from Large Language Models to create virtual populations with emotional and cognitive characteristics. Combines real census data with LLM-generated persona attributes.                                               | [Link](https://arxiv.org/abs/2409.10550)                                                 |
| PS09 | IQA-EVAL System                         | 2024            | Automatic evaluation system for human-model interactive question answering using LLM-generated personas. Provides framework for evaluating persona consistency and quality in interactive scenarios.                                                                            | [Link](https://arxiv.org/abs/2408.13545)                                                 |
| PS10 | Privacy Persona Auditing System         | 2024            | System using personas for democratizing end-user auditing of online content recommendations. Interprets advertising content based on persona attributes for privacy auditing and content recommendation transparency.                                                            | [Link](https://arxiv.org/abs/2410.04917)                                                 |
| PS11 | Auto-Generated Personas                 | 2024            | Automated pipeline for enhancing user-centered design practices among users. Combines visual and multimodal inputs with efficiency metrics for persona generation in educational settings.                                                                                       | [Link](https://dl.acm.org/doi/abs/10.1145/3613905.3651043)                               |
| PS12 | LLM-summarized Personas                 | 2024            | System using LLMs to summarize and convert user data into persona narratives through automated text generation. Part of human-AI collaborative workflows where humans select attributes and LLMs generate persona descriptions from grouped data.                                 | [Link](https://dl.acm.org/doi/10.1145/3643834.3660729)                                   |
| PS13 | CloChat                                 | 2024            | Interface supporting easy and accurate customization of agent personas in LLMs using GPT-4 and DALL-E2. Users materialize personas by interactively customizing traits, then converse with created agent personas.                                                              | [Link](https://dl.acm.org/doi/10.1145/3613904.3642472)                                   |
| PS14 | Impressona                              | 2024            | Text editor enabling writers to create AI personas of their target readers to receive on-demand feedback. Writers define persona attributes (background knowledge, job, role) and generate comments from that persona's perspective using LLM prompting with GPT-3.5.            | [Link](https://dl.acm.org/doi/10.1145/3613904.3642406)                                   |
| PS15 | Generative Agent Simulations            | 2024            | Novel agent architecture simulating attitudes and behaviors of real individuals by applying LLMs to qualitative interviews.                                                                                                              | [Link](https://arxiv.org/abs/2411.10109)                                                 |
| PS16 | Proxona                                | 2025            | Multiple persona interactive tool with annotated sections for persona customization, multiple persona cards, and expanded persona interaction. Demonstrates editing and interaction capabilities with multiple personas using LLMs for persona creation, evaluation, and delivery. | [Link](https://dl.acm.org/doi/10.1145/3706598.3714034)                                   |
| PS17 | Persona-L                               | 2025            | Uses LLMs and ability-based approach to generate personas of people with complex needs like Down syndrome. Features dataset collection, LLM model training, and integration with user interface providing backend API connections for persona creation and chat functionality. | [Link](https://dl.acm.org/doi/10.1145/3706598.3713445)                                   |
| PS18 | PersonaFlow                             | 2025            | Helps researchers generate interdisciplinary research ideas by simulating multiple domain experts using large language models. Instead of waiting for real experts to provide feedback, researchers can create customizable AI personas representing specialists from different fields. | [Link](https://dl.acm.org/doi/full/10.1145/3715336.3735789)                              |
| PS19 | SimTube                                 | 2025            | Generates realistic audience comments for videos before publication by analyzing video content and audience personas. Helps creators improve content before release instead of waiting for post-publication feedback.                                                             | [Link](https://dl.acm.org/doi/10.1145/3708359.3712146)                                   |
